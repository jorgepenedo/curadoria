# Aprofundamento de Formação — skin visual simples

Versão orientada à simplicidade de experiência:
- abertura direta no tema da formação;
- seção “Comece por aqui” com 3 recomendações;
- filtros simples por tipo;
- cards compactos com thumbnail;
- menos texto no mobile;
- mesma base CSV e mesma URL parametrizada.

No deploy, envie também a pasta `assets/`.
